# Ноутбуки выпусков

Здесь будет отдельный Jupyter Notebook на каждый выпуск. Ноутбук выпуска должен запускаться сверху вниз, показывать промежуточные результаты и явно отмечать ячейки, которые отправляют данные во внешний API.

Перед публикацией проверяем, что в ноутбуке нет ключей, личных данных и случайных выводов ячеек. Первый выпуск соберём вместе после утверждения его сценария.
