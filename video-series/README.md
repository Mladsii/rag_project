# RAG-видеосерия

Учебная серия на одном постепенно развиваемом проекте — помощнике магазина одежды.

## Структура

- `episodes/` — отдельный Jupyter Notebook для каждого выпуска.
- `production/` — планы выпусков, сценарии и заметки для записи.

Выпуск готовится по одному: сначала формулируем учебную цель, затем собираем и проверяем ноутбук, после этого готовим план записи. Исходный ноутбук проекта остаётся нетронутым; в эту папку добавляются подготовленные версии для выпусков.

## Черновой порядок тем

1. Базовый RAG: данные, эмбеддинги, поиск и ответ с источниками.
2. Проверка качества поиска и разбор ошибок.
3. Фильтры и гибридный поиск.
4. Reranker и Parent–Child retrieval.
5. Итеративный поиск и Agentic RAG на LangGraph.
6. Мультимодальный поиск товаров по фотографиям.

Порядок можно уточнять по результатам экспериментов и обсуждения сценария.
